Benchmark protocol

  • LP feasible: all eligible Netlib files under the 20,000-row cap, presolve enabled, hybrid LP mode.
  • LP infeasible: every file in the separate Netlib infeasible collection, 20,000-row cap.
  • MIP: five independent MIPLIB 2017 subset instances, official miplib2017-v36.solu references, reliability branching, 60 seconds per instance.
  • Certified MIP score counts only solver status OPTIMAL or a proven INFEASIBLE result with reference agreement.
  • Time-limit results remain visible as incumbents and gaps, but are not counted as exact.
